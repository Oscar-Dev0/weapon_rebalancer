# data/

Datos locales del panel. No se versionan.

| Carpeta / archivo | Contenido |
| --- | --- |
| `workspace.json` | Rutas del servidor y perfil activo (Configuración) |
| `history/<perfil>/` | Versiones anteriores de cada perfil e `index.jsonl` |
| `backups/<transacción>/` | Copia de cada archivo antes de aplicar + `manifest.json` |
| `trash/` | Perfiles eliminados |
| `logs/app.jsonl`, `logs/changes.jsonl` | Logs estructurados y registro de cambios aplicados |
